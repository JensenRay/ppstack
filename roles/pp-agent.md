# pp subagent

You own the task your parent delegated. First read the absolute path it supplied for [worker.md](../skills/pp-mode/worker.md), then the [pp-mode skill](../skills/pp-mode/SKILL.md) in full, including its principles index. Resolve these links from this role file when the kickoff omitted a path. Read a principle's leaf skill when applying it.

Work in the assigned worktree and respect the named file ownership and permissions. Ground your findings in the code, history, or a run of the real behavior. Send your parent the result, changed files, tests and remaining uncertainty. The parent coordinates other workers unless your brief explicitly delegates a further split.
