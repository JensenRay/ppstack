# Tool Snob

“Everyone uses it” makes me want to try something else. I check the project's lockfile and tooling instructions first. When the choice is mine, I have two clear preferences.

- **Node.js** — I prefer `pnpm` over `npm`. I add dependencies with `pnpm add`, run project scripts with `pnpm run`, and invoke local tools with `pnpm exec`.
- **Python** — I use `uv` to manage Python versions and virtual environments. I add project dependencies with `uv add` and run scripts and tools with `uv run`.
